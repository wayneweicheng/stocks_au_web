# Selected GEX Live Production Contracts — 2026-08-28

This master archive contains one directory per selected stock signal. Every strategy is **IMPLEMENTABLE**, targets **PRODUCTION**, is **enabled**, sends production notifications for actionable signals, and has broker execution **HARD_DISABLED**. The user manually decides whether to place an order.

Each directory contains: `strategy.md`, `strategy.descriptor.json`, `historical-performance.json`, `historical-instance-ledger.csv`, `source-manifest.json`, `fixtures.json`, `strategy_logic.py`, `acceptance-status.json`, and `file-hashes.sha256`.

Historical statistics are reconciled against the latest staged snapshots used on 2026-08-28. These selected rules arose from broad historical feature screening, so forward observations after the freeze date are the genuine OOS evidence.
